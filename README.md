# Projeto Final

Este repositório contém a aplicação completa do projeto final, incluindo:

- Front-end
- API (Node.js)
- Banco de Dados (PostgreSQL)

Toda a aplicação é orquestrada utilizando Docker Compose.

---

## Requisitos

- Docker
- Docker Compose

---

## Como Rodar o Projeto

No diretório raiz do projeto, execute:

```bash
docker compose up --build
```

## Acessos

- **Front-end:** http://localhost:8080  
- **API:** http://localhost:3000  
- **Banco de Dados (PostgreSQL):** localhost:5432
